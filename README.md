# About Framenaut

Framenaut is a low-cost, sturdy humanoid robot built by a student in Switzerland, as an Essentical project.

Most humanoid robots are expensive, fragile and locked away in research labs. Framenaut asks a different question: how cheap and how tough can a humanoid be while still being useful around people? The first build is a light, stick-figure humanoid, but the goal is bigger than one robot. The concept behind it is meant to carry over to any robot shape, so what is learned here can be reused on other machines later.

Framenaut is designed for real-world interaction with people. That means it has to be safe, gentle and predictable, not just strong. Every decision starts from three questions: does it keep the cost down, does it survive everyday handling, and is it safe to be near?

The project runs on a student budget, using off-the-shelf parts and a lot of testing. It is a one-person effort, and progress is steady rather than fast, so everything is documented openly as it happens. Current status: early prototype stage, with the first joints and sensors being tested.

## What you will find in this repository

- A parts list showing what the robot is made of and what is still needed
- A dated build log with photos and milestones
- Major achievements and results, as they are reached

## What you will not find here

Detailed designs, code or build instructions. The key technical work stays private for now, while the public documentation shows the journey and the results.
